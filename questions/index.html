WEIGHTball

“teach machine new tricks”

Machine Learning LabPart 2 · Linear Classifiers
MISSION

Make the machine less dumb.

SortBall used a Naive Bayes classifier. WeightBall uses a different kind of model: a linear classifier. You’ll decide what information it should consider, how strongly that information should matter, and then see how well your model handles new messages.
